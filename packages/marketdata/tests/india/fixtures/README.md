# Adapter fixtures

**These fixtures were not recorded from live traffic.** They are written by hand from each
provider's public API documentation (response examples and field lists), with values
adjusted to 2026 dates. They pin the response *shapes* our parsers expect. They do not show
that live responses still match; the Phase 2 PR lists everything that needs checking
against a real account.

- `kite/`: Kite Connect v3 docs, https://kite.trade/docs/connect/v3/
- `upstox/`: Upstox API v2/v3 docs, https://upstox.com/developer/api-documentation/
- `angel/`: Angel One SmartAPI docs, https://smartapi.angelbroking.com/docs
